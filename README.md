PCB-Based Home Security System Using GSM

Project Overview

A home security system designed using Arduino, a microwave motion sensor and GSM communication to provide motion detection and security alerts.

Objectives

- Detect movement using a motion sensor.
- Process sensor input using Arduino.
- Use GSM communication for security alerts.
- Provide LED status indication.

Hardware Components

- Arduino
- RCWL Microwave Motion Sensor
- GSM Module
- LED
- PCB

Working Principle

1. The motion sensor detects movement.
2. Arduino processes the sensor signal.
3. The GSM module is used for sending security alerts.
4. The LED provides visual status indication.
