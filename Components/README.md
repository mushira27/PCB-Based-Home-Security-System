Hardware Components

This folder contains the hardware components used in the PCB-Based Home Security System Using GSM.

Components and Their Functions

Component| Function
Arduino| Main microcontroller for system control
GSM Module| Enables remote GSM communication
RCWL-0516 Microwave Radar Motion Sensor| Detects movement
LED| Provides visual status indication
PCB| Integrates the electronic components

Technologies Used

- Embedded C / Arduino Programming
- PCB Design
- GSM Communication
- Microwave Radar Motion Detection
